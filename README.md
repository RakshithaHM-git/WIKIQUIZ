
# WIKIQUIZ

A Python-based quiz application that generates multiple-choice questions from Wikipedia article content using the Wikimedia Foundation's Wikipedia Structured Contents dataset.

## 📌 Project Description

WIKIQUIZ reads Wikipedia article data and uses the article information to create multiple-choice quizzes.

The project was integrated and tested in a Kaggle Notebook using the **Wikipedia Structured Contents** dataset provided by the Wikimedia Foundation.

The application allows users to select articles, answer questions, view their scores, and track quiz performance.

## ✨ Features

* 📚 Uses Wikipedia article data from the Wikimedia Structured Contents dataset
* 🔎 Search and select articles by topic keyword
* 🎯 Generates multiple-choice quiz questions
* ✅ Checks answers instantly
* 📊 Calculates score and percentage
* 📝 Stores quiz history
* 📈 Displays overall performance
* 📋 Displays quiz-wise performance
* 🔢 Shows total questions, correct answers, wrong answers, and percentage
